# Brand Logo Guide - How to Add Logos

## ❌ Wrong URLs (Won't Work)
These are webpage URLs, not image URLs:
- `logo.com/blog/apple-logo` ❌
- `logos-world.net/apple-logo/` ❌
- `brandlogos.com/apple` ❌

## ✅ Correct URLs (Will Work)
These are direct image URLs:
- `https://example.com/logo.png` ✅
- `https://example.com/image.jpg` ✅
- `https://example.com/brand.svg` ✅

## How to Get Direct Image URLs

### Method 1: Google Images (Best for Quick Use)
1. Go to Google Images
2. Search: "Apple logo PNG transparent"
3. Click on an image
4. Right-click the image → **Copy image address**
5. Paste in Brand Logo URL field

### Method 2: Wikimedia Commons (Best Quality)
1. Go to https://commons.wikimedia.org
2. Search: "Apple logo"
3. Click on the image you want
4. Look for the file URL (usually ends in .svg or .png)
5. Copy and paste

### Method 3: Upload Your Own (Recommended)
1. Download logo from anywhere
2. In Brand Management, click **Add Brand**
3. Switch to **Upload** tab
4. Click to upload your logo file
5. System automatically uploads to Cloudinary
6. Permanent URL is saved

## Tips for Best Results

✅ **Do:**
- Use PNG files with transparent backgrounds
- Use SVG files for scalable logos
- Use square images (200x200px or larger)
- Use Wikimedia Commons for official logos
- Upload to Cloudinary for permanent hosting

❌ **Don't:**
- Use webpage URLs
- Use very small images (less than 100x100px)
- Use copyrighted images without permission
- Use images with watermarks

## Troubleshooting

### "Image not loading" or "403 Forbidden"
**Problem:** You're using a webpage URL, not an image URL
**Solution:** Right-click the image and "Copy image address"

### "CORS error"
**Problem:** Website blocks external access
**Solution:** Download the image and upload via Upload tab

### "Image not showing preview"
**Problem:** URL might be incorrect
**Solution:** 
1. Paste URL in browser address bar
2. If it shows the image directly, URL is correct
3. If it shows a webpage, find the actual image URL
